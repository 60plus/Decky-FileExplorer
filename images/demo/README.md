# Image-viewer demonstration artwork

[Aurora-lake.png](Aurora-lake.png) and
[Coastal-lighthouse.png](Coastal-lighthouse.png) are generated artwork used to
demonstrate the FileExplorer image viewer. They are not photographs of real
locations.

The screenshots showing these images inside FileExplorer are actual SteamOS
captures. The original images are documentation and demonstration assets; they
are not bundled with the plugin.
